## T-V3

The first run wrote 500 documents of about 100 bytes and failed. Time per write rose from 0.36 s to 7.2 s, it stopped at 353 documents without reporting anything, and SAMMI then showed a fatal error on Set String for the absent `d499`. D32 followed. The passing run crossed the message cap with 56 KB in 8 documents, then survived a Bridge reload and a SAMMI restart with OBS open.

Write speed with hundreds of documents has not been measured on the PC since D32.
